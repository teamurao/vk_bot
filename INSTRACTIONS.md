# Как получить токен сообщества VK для бота

## 1. Создайте сообщество

1. Создайте сообщество (можно на любую тематику)
1. Откройте: `Управление сообществом -> Управление` 
3. Включите пункт: `Сообщения сообщества`.

## 3. Включите бота

1. В разделе `Сообщения` откройте `Настройки для бота`.
2. Включите возможности бота (чтобы он получал и отправлял сообщения).

## 4. Создайте ключ доступа (access token)

1. Перейдите: `Управление -> Дополнительно -> Работа с API`.
2. Нажмите `Создать ключ`.
3. Отметьте права:
   - `messages`
   - `groups`
4. Подтвердите действие.
5. Скопируйте токен и сохраните в безопасном месте.

Важно: токен можно посмотреть несколько раз, но для этого необходимо подтвердить действие через смс или уведомление в мобильном клиенте.

## 5. Узнайте ID сообщества

- В разделе `Управление` есть `ID сообщества`.
- Также ID можно взять из URL/настроек.
- ID - числовой тип данных, написан после @club...

## 6. Подставьте токен в проект

```python
TOKEN = "vk1.a...."
GROUP_ID = 123456789 # после @club...
```

Рекомендуемый вариант:

- хранить токен в переменной окружения `VK_BOT_TOKEN`;
- не коммитить токен в Git.


## 7. Частые ошибки

- `User authorization failed`: неправильный токен или истек ключ.
- Бот не отвечает: не включены сообщения/настройки бота в сообществе.
- Ошибки доступа: при создании ключа не выбраны нужные права.
